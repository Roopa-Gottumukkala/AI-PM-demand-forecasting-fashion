# AI-PM-demand-forecasting-fashion
AI Product Manager Fashion Industry, Supply Chain Intelligence — owning the forecasting product that Merchandising, Planning, and Logistics use to set buy quantities and react to disruption risk.
Building and validating a SKU-family-level demand forecasting model with an integrated freight/cost disruption simulator, quantify the £ impact of 3 disruption scenarios, and produce a recommendation on buffer stock / dual-sourcing / freight-mode policy that a VP of Supply Chain would actually sign off on.
